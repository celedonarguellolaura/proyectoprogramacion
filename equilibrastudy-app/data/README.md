# 📁 Capa de Datos — JSON como Base de DatosEsta carpeta actúa como capa de persistencia del sistema.**Regla de Oro:** Los archivos JSON aquí contenidos **jamás son accedidos directamente desde el cliente**.Toda lectura ocurre exclusivamente en Server Components o Route Handlers.## Archivos| Archivo | Propósito ||---------|-----------|| `config.json` | Configuración global de la aplicación (nombre, versión, locale, tema) || `home.json` | Contenido de la página principal (hero, meta, animación) |## Cómo agregar un nuevo archivo JSON1. Crear el archivo `data/mi-entidad.json` con la estructura deseada.2. Agregar la interfaz correspondiente en `lib/types.ts`.3. Agregar el schema Zod en `lib/validators.ts`.4. Agregar la función de lectura en `lib/dataService.ts`.5. Consumir desde un Server Component o Route Handler únicamente.## Reglas- Solo lectura desde el servidor.- Validación obligatoria con Zod antes de usar los datos.- Un archivo por dominio conceptual.- Sin lógica en JSON — solo datos puros.
